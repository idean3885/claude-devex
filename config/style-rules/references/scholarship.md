# 번역학·코퍼스 근거 (AI 티 분류 SSOT)

이 문서는 `base/ai-tells.md` 의 분류(특히 A 번역투 계열)가 어떤 번역학·코퍼스 연구에 기반하는지 기록하는 **학술 근거 SSOT** 다.
`base/ai-tells.md` 는 개별 패턴 행에서 이 문서를 anchor 로만 가리키고, 학자명·연도 등 전문(full text)은 여기에 둔다.

> **위치**: `references/` (base 아님). 세션 예산 보호를 위해 SessionStart hook 의 상시 미러 대상에서 제외한다.
> `~/.claude/ops-agent/style-rules/` 로 미러되지 않으며, 근거 추적이 필요할 때만 이 경로를 직접 참조한다.
>
> **출처·라이선스**: `epoko77-ai/im-not-ai` (MIT) 의 `scholarship.md` 를 우리 맥락으로 축약 이식했다.
> 학자명·연도·저널은 추적성을 위해 보존하고, verbatim 인용은 최소화한다(표 중심). 본 문서도 동일 MIT 로 배포된다.
>
> **분류 vs 근거 분리**: 이 문서는 근거 기록이며 심각도(S1/S2/S3) 판정 권한은 `base/ai-tells.md` 에 있다.
> 아래 매핑은 근거가 어느 패턴을 뒷받침하는지를 나타낼 뿐, base 본문을 대체하지 않는다.

## 8유형 번역투 학자 계보 (anchor 표)

"우리 대응" 열의 `(gap)` 은 base 에 직접 패턴이 없어 인접 패턴으로만 근사됨을 뜻한다.

## Caveat (우리 신규·조정 항목에 직접 영향)

업스트림 caveat 중 우리 분류의 심각도·적용 범위 결정에 직접 근거가 되는 항목만 발췌한다.
근거의 종류를 구분한다: (U) 업스트림 verbatim 근거, (C) 우리 맥락 보정.

### CV1. post-editese·합성 지수 미채택 (U: 업스트림 C3)

Toral 2019 의 post-editese 3축(simplification·normalisation·interference)과 이를 가중 합한 합성 지수는 **speculative** 다.
검증 언어쌍(en→de, de→en, es→de, en→fr, zh→en)에 **한국어가 없고**, baseline(비번역 한국어 대비) 없이는 정량 판정이 불가하다.
→ 우리는 이 지수들을 metrics 로 **채택하지 않는다**. 정성 anchor 로만 참조한다.

### CV2. A-6(대명사)는 번역·요약 맥락 한정 조건부 (U: 대명사 밀도 근거 + C: 조건 게이팅)

업스트림 실증은 "한국어 **번역·요약 출력**의 대명사 밀도가 비번역 한국어의 2~3배" 라는 것으로, 근거의 사정거리가 번역·요약 산출물에 있다(U).
자생(원생) 국어 산문에서는 인간 필자의 대명사 사용 양상이 달라, `그/그녀/그것/그들` 반복을 무조건 AI 티로 볼 수 없다(C).
→ A-6 은 **번역·요약 맥락에서 S1 급 강도로 게이팅**, 그 밖의 자생 산문에서는 S2 로 유지하는 **조건부 패턴**으로 둔다.

### CV3. A-1(~을 통해)·I-1(것이다) S2 강등 근거 (C: 코퍼스 보정, U: C5 방법론 유추)

실증 코퍼스상 `~를 통해`·`것이다` 는 비번역 한국어에서도, 나아가 인간 필자가 오히려 더 빈번히 쓰는 경향이 관찰된다(C).
이는 업스트림 C5 의 방법론(단순 `~의` 는 15세기부터의 자생 표현이라 번역투 탐지 대상에서 제외)과 같은 구조의 논거다(U).
→ 현재 base 에서 **S1** 인 A-1·I-1 은 자생 한국어 사용 빈도를 감안해 **S2 강등을 검토**할 근거가 된다(판정은 base 소관).

### CV4. A-9 단순 `~의` 탐지 제외 (U: 업스트림 C5)

`~의` 자체가 일본어 번역투인지에는 학계 합의가 없다(국립국어원 등은 15세기부터 존재로 봄).
→ A-9 는 `~에서의/~에로의/~으로의/~에의` 이중 결합만 탐지하고 **단순 `~의` 는 명시적으로 제외**한다.

### CV5. 종결어미·쉼표 분절 지표는 estimated (U: 업스트림 C1)

김혜영 2019 의 평서형 `-다` 출현 빈도 등 본문 정량 수치는 원문 PDF 미확보로 미검증이다.
→ E-2(종결어미 반복) 임계치와 쉼표 분절(comma-segmentation) 길이 지표는 확정 수치가 아니라 **estimated 플래그**로 다룬다.

### CV6. 8유형 단일 실증 부재 + LLM 진화 (U: 업스트림 C4·C6)

8대 유형 전체를 단일 NMT/LLM 실증으로 다룬 논문은 확인되지 않으며(C4), LLM 품질 평가는 노후화가 빠르다(C6).
→ 8유형 재현율은 유형별로 개별 추적하고, 근거 기반 판정에 `valid as of 2026-05` 를 병기한다.

## 경량화 원칙

- 표 중심, verbatim 최소. 학자명·연도는 추적성을 위해 보존한다.
- base 본문 직접 수정 권한 없음. 이 문서는 근거·매핑만 기록한다.
- `(gap)` 항목(무생물 주어·'-들'·시제서법·호칭)은 base 미커버 영역이며, 신규 패턴 신설 시 후보다.
